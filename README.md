# CarDEX - Car Explorer

**CarDEX** is a modern and interactive Car Explorer website built with HTML, CSS, and Vanilla JavaScript. Users can explore different car brands and models, search cars, view details, check safety recalls, and save their favorite cars.

## Features

- **Car Explorer:** Explore cars from different brands.
- **Brand Filter:** Browse cars by popular manufacturers.
- **Year Filter:** Select different model years.
- **Search:** Find cars by name or brand.
- **Car Details:** View model information and IDs.
- **Car Images:** Find car images using Wikipedia API.
- **Safety Recalls:** Check vehicle safety recall information.
- **Favorites:** Add or remove favorite cars.
- **Local Storage:** Save favorites in the browser.
- **Responsive Design:** Works on desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- NHTSA vPIC API
- NHTSA Recall API
- Wikipedia API
- LocalStorage

## APIs Used

**1. NHTSA Vehicle API**

Used to fetch car brands and models.

https://vpic.nhtsa.dot.gov/api/

**2. NHTSA Recall API**

Used to retrieve vehicle safety recall information.

https://api.nhtsa.gov/

**3. Wikipedia API**

Used to search for car images.

https://www.mediawiki.org/wiki/API:Main_page
